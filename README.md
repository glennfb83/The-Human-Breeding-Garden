# The Human Breeding Garden

A tiny, dependency-free browser game about wandering through a strange static garden and growing a network of trust. It is intentionally self-contained: there is no server, build step, account, or popup dialogue.

## Play

Open `index.html` in a browser. Use **WASD** or the arrow keys to move the coral signal around the garden. Walk near a person and press **E** or **Space** to open their signal. You can also click a name in **Known signals** to travel directly to them.

The inline field notes teach the basic loop without leaving a permanent instruction overlay. Meet people, offer sun seeds, and revisit strong connections with bright ink to make hybrid fruit.

## What is included

- Canvas-based exploration with an intentionally low-fi, static web aesthetic.
- A responsive sidebar with tutorial notes, contacts, inventory, and a live garden log.
- Nine networkable characters: Big P, Max, Leif, GlennFB, Cling22, Benjamin Netanyahu, Charlie Kirk, IceMan, and FireMan.
- Lightweight trade and relationship progression held entirely in browser memory.
- No external game engine, image assets, API, or pop-up confirmations.

## Files

- `index.html` — semantic game shell and interface panels.
- `styles.css` — paper/static visual system and responsive layout.
- `main.js` — movement, canvas rendering, characters, tutorial, networking, and inventory.

## Note

The named characters are fictional in-game personas for this playful prototype. Refreshing the page starts a fresh garden because persistence is deliberately not part of this foundational version.
